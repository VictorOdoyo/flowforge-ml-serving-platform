# Changelog

## 0.1.0

- Added FastAPI application shell with versioned API routing.
- Added SQLAlchemy models, repositories, and Alembic migrations.
- Added JWT authentication, role checks, and password hashing.
- Added durable job submission, idempotency handling, and state-machine validation.
- Added Redis-backed rate limiting and readiness checks.
- Added Celery workflow execution and maintenance scheduling.
- Added unit and integration tests with coverage enforcement.
- Added Docker Compose, Nginx, and Kubernetes deployment assets.
- Added CI, container publishing workflow, and Dependabot configuration.
- Added architecture, operations, deployment, security, and local development documentation.
